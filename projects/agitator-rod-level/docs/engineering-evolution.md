# Engineering Evolution

## 1. V1.5 — comparing the shaft with an empty-tank reference

### Approach

空タンク時の映像を基準にし、撹拌軸の帯を 64 区間に分けて、区間ごとに軸方向のエッジ構造を基準と比較しました。一致する区間を「軸が見えている」、一致しない区間を「隠れている」とし、その間に境界候補の帯を表示しました。

### Problem

- 出力は「どこまで軸が見えているか」の診断であり、**液面の位置そのものは出せなかった**
- 一致しない理由が「スラリーで覆われた」のか「曇り・反射・回転による見え方の変化」なのかを区別する仕組みがなかった
- 空タンクの基準映像を毎回用意する必要があった

## 2. V1.6 — use what slurry actually looks like

### Change

基準との比較をやめ、**スラリーに覆われた軸の見た目そのもの**（ほぼ白飛びして平滑）を特徴にしました。境界は「上は露出・下は被覆」の最適分割で求め、しきい値を持たない形にしました。

### Result

基準映像なしで、各フレームから液面の % と信頼度が出るようになりました。誤検出フレーム（曇り・照明反射）の信頼度は約 0.41〜0.45 に集まっていたため、採用の下限を 0.6 にしました。

## 3. Tilted waterline

### Issue

液面は水平ですが、カメラの角度のため、液面と撹拌軸の交線が帯の横方向に対して斜めに写ります。帯の 1 行をそのまま水線とみなすと、境界付近の行には露出部と被覆部が混ざり、行平均で境界を探す前提が崩れます。

### Change

帯を幅方向に 8 本に分けてそれぞれ境界を求め、傾きを直線で当てはめる**自動校正**を追加しました（液面がはっきり見えるフレームの中央値）。校正した傾きで帯をせん断してから行平均をとります。

## 4. "No output" was three different situations

### Symptom

あるクリップ（液面が出始める直前の時間帯）で、全フレームが「液面なし」になりました。ROI の範囲が足りないのか、検出に失敗しているのかを判断する必要がありました。

### Analysis

- 全フレームで最適分割は `k = 512`（被覆部なし）、信頼度は負。帯の明度は最大でも約 220 で、白の下限 222 に届いていなかった
- 次のクリップで液面が約 3% から現れ、その後約 10% で安定 → 液面が下から上がってきたことと整合する
- 1 日分の映像を時間帯ごとに並べて見ると、「液面なし」には次の 3 種類が混ざっていた

| Situation | Shaft | Region under the shaft |
|---|---|---|
| Empty tank / after draining | 全長がはっきり見える | 暗め（L ≈ 210〜225） |
| Lens fog during feeding | ぼやけている | 白飛び（L ≈ 241） |
| Slurry at the bottom, not yet touching the shaft | 全長がはっきり見える | **灰色（L ≈ 215〜225）— 空タンクと同程度** |

### Decision

- ROI は撹拌軸の下端までで既に最大。下へ広げるとタンク底や撹拌翼が入り、液面がないときにも偽の液面を出すため、**広げない**
- 「軸が全長露出している」と「見えない」は、軸の下の領域の明るさで分けられる → `below_rod` と `no_surface` を追加（V1.6.3）
- 「軸に届く前の灰色のスラリー」は、空タンクの底と明るさが同じで、単一フレームでは区別できない。白く見えるようになると十数秒で軸に届き、通常の液面として測れる。この区別は**行わない**ことにし、制限として明記した

### Result

既存の液面出力は変えずに（代表クリップで値が一致することを確認）、空タンク・排出後が `below_rod`、曇りの期間が `no_surface` に分かれるようになりました。
